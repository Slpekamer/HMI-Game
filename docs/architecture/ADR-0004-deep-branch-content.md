# ADR-0004 — C2 differentiated branch content

Status: accepted for local implementation (parent authorization 2026-10-31). Depends on C1 `d330c6b`.

Add eight nodes, not a filler numerical target. Three two-member exclusive groups choose orbit geometry, ricochet reach versus mobility, and impact range versus force. Two fusions require multiple trait roots and ranked/alternative prerequisites. Every effect uses an already registered typed domain; no new damage callback, trigger, or system is introduced. No animation authority and no Dodge.

The original 21 card definitions, four items and five character definitions remain semantically identical. Their schema1 bytes are preserved as a test fixture; the production catalog becomes schema2 with a new prototype balance version. Tests compare the production legacy prefix, items and heroes against that frozen fixture, not just the fixture against itself. The whole old suite continues against legacy input. New production tests cover legal branches, stat effects/domain isolation, all-five/multi-seed finite progression and every legacy card's reachability. The original baseline digest must remain unchanged on legacy input; added options intentionally change production offer sequences.

C2 itself does not add endless progression, checkpoints or richer enemy behaviors. The adapter must expose prerequisites and exact downsides; core tests do not prove that UI is readable. Parent integrates and validates presentation separately.
