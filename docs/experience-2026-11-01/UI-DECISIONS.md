## 红门必须保留

- 首版竖屏钱包 icon 与余额文本重叠、暂停面板过长：原生发现后已修，不能用此前 bounds 通过冒充视觉通过。
- 新断言 fixture 的累计 confirm 计数错误已修，纯测试问题与产品问题分开。
- 一次 importer exit 0 仍打印 EditorSettings shutdown ERROR，严格拒绝；同源 fresh 一次重试通过，不声称引擎 race 已解决。
- UI detach 测试断言全过后，直接 `Free()` 清理发生 `!rc_owner` / unsafe resource reference shutdown fatal。改用生产惯用的 `QueueFree()` 后同类真实 detach gate 退出 0；保留前红日志，不将该对照扩大成引擎根因已证实或全面稳定承诺。
- 响应式 UI-only 图不代表主世界、自然生存或手机效果；r3 窄屏主世界因角色过小与地板边缘暴露已被独立拒绝。后续相机候选由负责人另树处理。
