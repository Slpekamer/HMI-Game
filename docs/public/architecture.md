# Historical experimental architecture

Portable fixed-tick C# ECS remains gameplay authority. The Godot adapter owns presentation and input routing. This archive uses its original rule-2 instantaneous-ray baseline and generation-safe events. It is not the later rule-3 projectile implementation. Core damage, enemy movement and camera behavior are not changed by the archived visual experiment.

The current implementation details and rejection/limitations are summarized in [experiment status](experiment-status.md). Experimental body direction and cue geometry are not new attack collision rules. Source code and actual runtime assets are preserved; public documentation only narrows the published history.
