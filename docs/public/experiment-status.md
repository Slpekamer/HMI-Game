# Ready / Strafe and rejected melee-priority aim

This archive combines the earlier ready-attention/Strafe research baseline with the completed melee-priority experiment; it avoids publishing each near-identical diagnostic copy as a separate feature. It is a historical rule-2 instantaneous-ray baseline, not the newer real-projectile integrated game.

The visual-only attention module observed existing enemies and bounded root rotation while retaining Core movement. A pilot StrafeR clip was used only in a restricted rightward movement region. The four-clip experimental Crit asset adds StrafeR to the original Idle/Run/Attack set; it is intentionally not the canonical three-clip production asset. Short-leg scale limited visible step amplitude. Do not run a validator that requires exactly three clips and then hide the expected mismatch.

The later optional melee-priority policy consumed genuine Melee direction even when the native animation merged the event into an existing gesture. It did not replay a gesture for every hit, change damage, or modify Core target selection. Its sequence/owner/scope protections are part of the archived implementation.

Actual controlled imagery showed some corrected target facing but additional whole-body back-and-forth turns. In the short eleven-Melee-event sequence, event-frame errors above 45 degrees rose from two to three. The separate nineteen-event headless series and integrated error metrics are not interchangeable with that native sample. A lower angular-error integral did not establish visual comfort. The owner rejected adoption of the every-Melee direction policy. The ready/Strafe baseline had only limited direction benefit and did not establish natural full-direction gait.

Recorded checks included 171 pure aim tests, scoped multi-rate headless comparisons, lifecycle negative/positive tests and an 8.5-second native controlled comparison. The scene intentionally used elevated player HP, two controlled enemies and disabled spawn cadence after setup; it is not ordinary balance or survival evidence. Strict editor shutdown diagnostics remain separate. Original media and full operational logs are retained outside this public source.

The current stationary-Launched-facing work is a different unfinished candidate and is not part of this archive.
