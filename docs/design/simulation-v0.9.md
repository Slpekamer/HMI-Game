# v0.9 实际 HTML 模拟规则与参数

本文明确记录“代码当前怎样工作”，不是要求 Godot 原样照搬。全部长度是 SVG 示意坐标，时间是演示累计秒，不能默认对应米或最终游戏秒。所有函数全文见 [源摘录](html-v0.9-reference.md)，目录见 [JSON](catalog-v0.9.json)。

## 1. 卡片抽取与配置公式

目录顺序参与抽签，来源序为：五根 `orbit,crit,honey,summon,bounce`，随后 orbit.more/wide、crit.chain/reach/relay、honey.wide/sticky、summon.team、bounce.reach/force、base.health/speed/range、risk.bounty/glass/fleet。

- `initial(character, seed)`：该角色根节点等级1，其他0，picks=[]。
- 可抽：当前等级 `< cap` 且没有前置或父等级满足 `parentLevel || 1`。不额外做角色排他；当前没有互斥节点。
- offers：已选5张返回空，否则每类trait/base/risk分别过滤可用池，从池中按 hash 取一个；不会在render消耗随机状态。
- hash输入：`seed + '|' + character + '|' + picks.join(',') + '|' + slot`。算法初值2166136261，依次对字符码xor，再 `Math.imul(x,16777619)`，末尾 `>>>0`，对池长度取模。此FNV式实现遍历JS字符，当前ID均ASCII；生产可改算法但须版本化，不能保持旧seed却静默换结果。
- choose只接受当前offers内ID，复制levels并+1，picks追加；非法ID抛错，运行经济层提前拒绝。
- UI初始seed1030，输入截断为整数且限制1–999999，空/无效/0回退1030；“下一个种子”999999循环到1。模型本身不包含UI输入规范化。
- 当前5选择长度下三个池不会耗尽（基础每种上限5，风险上限合计5）；如未来增加波次数需重审，不能无限延长后依然声称永远有候选。

令 `L(id)` 为等级（未拥有=0）：

|配置|实际推导|
|---|---|
|mechanisms|拥有根的五key，固定目录序；不再限制3种|
|damage / speed|基础分别固定1；不由基础卡提升全局伤害/移速|
|health|`1 + .10*L(base.health)`|
|basicSpeed / basicRange|分别 `1 + .10*L(base.speed/range)`|
|orbitCount / orbitRadius|`2+L(orbit.more)` / `76+12*L(orbit.wide)`|
|ricochetBounces|`1+L(crit.chain)+L(crit.relay)`，最大4|
|ricochetRange|`120+45*L(crit.reach)`，最大210|
|honeyRadius / honeySlow|`103+14*L(honey.wide)` / `.45-.10*L(honey.sticky)`|
|summonCount|`min(4, (初始角色summon?2:1)+L(summon.team))`；跨学根1位，最多升级到3位，初始棉队可到4位|
|impactRange / impactForce|`68+6*L(bounce.reach)` / `220+35*L(bounce.force)`|
|enemyHealth / coinMultiplier|`1+.5*L(risk.bounty)` / `1+L(risk.bounty)`；最大2倍血与3币|
|basicDamage / playerHealth|有risk.glass则1.6/.65，否则1/1|
|enemySpeed / playerSpeed|各 `1+.2*L(risk.fleet)`，最大1.4|

**风险作用域**：玻璃牌只乘普通近战，不乘星环/弹射/蜜圈/伙伴/冲击；加速齿轮作用英雄移动及敌人普通移动/冲锋，不加攻击频率。悬赏改变新波敌人最大血与每次有效死亡的金币，不是金币拾取倍率。

模拟输入另有防御性clamp（不是目录能合法达到的成长值）：damage .1–5；最终health .3–5；基础speed .7–2.5；basicSpeed .5–3；basicRange .5–2；orbitCount整数2–4、radius60–110；反射整数1–4、搜索60–300；honeyRadius80–145、速度系数.25–.8；召唤整数1–4；冲击距离45–80、推力100–300；敌HP倍率1–3、金币整数1–4、基础伤害倍率.5–3、敌我移动风险倍率.5–2。机制去重后最多5。输入通常用`Number(value)||default`，不等于生产严谨schema校验。

## 2. 共用战斗基线与伤害计算

- 英雄初始 `(480,235)`，最大生命100×最终health；固定路线 `x=400+80*cos(clock*.45), y=235+48*sin(clock*.45)`，clock随有效移速推进。没有真实摇杆/移动输入/冲刺。
- 所有人普通近战：射程46，基础伤害1.5，冷却.72秒；选最近活敌，目标在距离内才出手。动画白扇半角.65弧度只是反馈，实际普通攻击只伤一个目标，不是全扇AoE。
- `basicReach = 46*basicRange`；`effectiveBasicSpeed=basicSpeed*(汽水且time<10?1.2:1)`；普通攻击间隔`.72/effectiveBasicSpeed`。
- 普攻原伤害 `1.5*(1+.08*护套数)*risk.basicDamage`，再走统一hit乘有效全局伤害。基础范围/速度卡不改变特性射程/冷却。
- `effectiveDamage = config.damage + (场内强攻未到期?.25:0)`；hit对所有来源使用这个倍率，包括碰撞。伤害护套、玻璃牌则只在普攻来源乘，不混成全局。
- `effectiveSpeed = (config.speed+.08*鞋垫数)*risk.playerSpeed + (场内轻快未到期?.2:0)`；鞋垫先加基准再乘风险，临时轻快最后加。
- 最终health为`clamp(base.health*risk.playerHealth*(护符?1.25:1),.3,5)`，上限生命`100*health`。基础生命UI不含商店临时倍率，战斗状态包含。
- 所有普通敌最大血`8*risk.enemyHealth`。接触距离<30、距其最近hitAt>.7秒时扣英雄7生命、闪白.2秒并把敌人向外移25；**hitAt也被我方伤害刷新**，这是原型耦合，不应自动认定正式无敌帧规则。
- 英雄HP<=0立即补满并显示效果；下一波也恢复满生命。均为演示便利，正式死亡/治疗系统未实现。

## 3. 五个特性的当前模拟

### 星环

2–4颗按等角分布；角度 `time*2.1 + j*2π/count`，轨道半径76/88/100。敌人与糖距离<25且`time-hitAt>.3`则伤害2.1，当前目标本轮break。所有糖共享该敌人的hitAt，其他伤害也刷新它。不是多颗无冷却叠伤；内侧不一定命中，需普通近战补位。

### 有限弹射

每.85秒尝试首发：英雄260内活敌、有墙体视线，取最近；可找不到目标。首击伤害3，随后最多ricochetBounces次搜索：**以刚命中的敌人位置为圆心**，范围ricochetRange，过滤本条链visited ID与死亡目标及墙遮挡；距离最近优先，同距ID升序。没有合法下一目标立即终止。第h跳伤害`3*.5^h`（h从1起），单链不重打同一敌人。

首发和各跳都有墙LOS：每段最多5坐标单位步进，障碍膨胀半径2。线段是可视轨迹，伤害即时应用，不是拥有飞行时间/实体碰撞的真实弹丸。最多16条轨迹，寿命首发默认.2秒、后跳.3秒。橙淡圈只是显示搜索范围。

### 蜂蜜领域

半径103/117/131，圈内敌速乘.45/.35/.25；每.6秒对圈内每活敌伤害1.25。当前扩圈不降低单位伤害，没有独立蜜路/驻地场实体、减速抗性或Boss规则。圈以英雄位置为圆心；当前没有单独技能施放输入。

### 独立伙伴

- 初始部署公式：x=435+(i%2)*90，y=280+floor(i/2)*40；位置与锚点ax/ay独立于主角。偶数位射手，奇数位支援。
- 射手射程125、锚点leash140；支援射程76、leash125；初始CD=.15+i*.25。
- 游走：按伙伴与部署点筛选可达目标，敌距锚点≤leash+range；伙伴→敌及锚点→敌都需5步长/半径13墙检查，按距伙伴排序。没有目标回锚点；射手靠近至射程*.68，支援靠近至100；目标位置限制在部署leash内。射手速度42，支援32；墙移动用半径13。
- 驻守：保持当前位置，不追主角，不做上述自主移动；仍在自有范围内攻击/支援。
- 射手CD.95，命中伤害2.7；处于伙伴buff时3.2；投射线从伙伴坐标起，寿命.28秒，不从主角出发。
- 支援CD1.8：英雄在76内回血2，上限当前maxHP；范围内其他伙伴获得1.5秒buff；不是独立受击护盾或坦克AI。
- 明确召回/重部署：各伙伴放在英雄附近（首位x−38，后续x+38，y+40，边界clamp），重设锚点、CD.2、清buff与旧伙伴射线；后续不会自动跟随。多伙伴可重叠，未做正式队形避让。
- 切角色恢复roam；下一波恢复初始部署位置，模式可保留。伙伴HP、寿命、被杀、召回CD、蜂蜜支援、合体队长均未实现。

### 窄扇冲击、碰撞与墙反弹

额外冲击基准range68/升级74/80，半角π/7（总51.43°），伤害2.1、CD1.4，朝最近目标；扇内活敌均受击，存活者赋方向速度220/255/290。不是扩大成大扇。

一次击退持续最多.8秒，速度指数衰减`exp(-2.3*dt)`。敌撞墙法向对应分量反向×.75，反弹间隔>.08秒，每次击退最多3次，达到则清速度/结束击退。边界也可触发反射。移动分段不大于5坐标单位，避免跨墙；普通敌绕墙上/下缺口而不是穿过。

被击退活敌与其他活敌距离≤37，且该无序实体对1.2秒冷却已过，可在另一敌当前位置触发半径55、伤害1.8的AoE。每次击退最多一次（blastUsed）；伤害可影响碰撞双方，**AoE不再触发新击退**，不无限递归。新击退重置blastUsed。对已死亡目标跳过。源码定义的pair冷却按敌ID而非生命序列，短期重生可能仍受旧对冷却，这是原型边界。

## 5. 经济、波次与实例寿命

权威状态：runToken、wave、phase、cards、coins/earned/spent/kills、cardPicked、queued、gear、active、stock；seen集合拒绝重复生命实例。快照返回JSON深拷贝。无持久化存档，页面刷新也会新局，刷新不会保留钱包。

- reset：新token递增、wave1、phase combat、0币/0消费、初始根、空装备/排队物品、各stock1；此时暂停待播放。
- onKill：仅combat，token/wave匹配，enemyLifeId为非空string/number且未处理。key=token|wave|enemyLifeId；收益从卡模型重新计算，忽略事件自报金额；coins/earned/kills同时增。模拟enemyLifeId包含wave:id:life。旧token/旧wave/重复事件一律无收益。
- finishWave：仅同局同波combat有效，一次性；wave1–5→between，wave6→complete。没有通关额外金币。暂停所有战斗和计时，播放/结束按钮禁用。
- offers：仅between且cardPicked=false。choose成功后免费等级+1，cardPicked=true；重复选择拒绝。买道具不消费免费卡名额。
- buy：已知道具、between、库存>0、消耗品未排队/装备未到cap、coins≥price全部满足才原子扣费、spent增、stock减；无效操作不改变账本。
- nextWave：仅between且cardPicked。wave+1，queued消耗品转active，gear复制为active；清queued、stock各回1、cardPicked=false、seen重建，coins原样保留。phase combat、场景/本波计时重置并暂停。第6波不会再开商店或免费卡。
- 护符入场当波生命×1.25，整波有效；下一波无新购买即消失。汽水入场生效，仅`time<10`基础攻速×1.2；暂停不推进time，不跨下一波保留。装备累计至2，直到显式新局。
- 全局余额只有shopmodel权威值；SVG另有本波赚取计数但不作为钱包。HUD同时显示本波与可用。`coins=earned-spent>=0`为不变量。
- 同wave render/选卡/买道具/切tab不得resetScene；setGameplayRunState只有token或wave变更才重置。停止战斗后改卡不会生成新的可领奖敌人。

## 6. UI、可访问性与运行限制

五角色起点按钮；播放/暂停；“演示快进结束本波”（无奖励）；波末免费卡、去商店、进入下一波；三个Tab：构筑/卡树/道具；种子输入、应用重开、换种子重开；明确“重开整局·清空金币”。v0.9没有重播按钮。角色切换/seed变更也重开全部经济与装备。

卡树显示已拥有/满级、可获取、缺前置，点击看ID/前置/效果而不是直接购买节点；图鉴和抽牌共享目录。Tabs支持左右/Home/End键与aria-selected/aria-controls；按钮键盘可达，有focus-visible、中文lang、图片alt、aria-live状态；触屏尺寸控件和窄屏单列，减少动画偏好默认暂停，页面隐藏自动暂停。此可访问性设计未经过正式辅助技术合规审计。

requestAnimationFrame推进，单帧dt封顶.04；时间按模拟累积，慢设备会延长墙钟时长。暂停取消帧请求并清last；波结束再进入的回调检查playing而退出。此**不是固定tick或跨平台确定性保证**。最多8敌、16条射线、20个效果、4伙伴；切状态清理射线/效果/计时/碰撞对。没有真实联网、保存、后台服务器或云金币；所有交互在本页内存完成。图片/CSS/JS内嵌，无CDN/外部字体依赖。
